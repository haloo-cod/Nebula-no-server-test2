# Starlitn'blog

这是 [Nebula](https://github.com/haloo-cod/Nebula) 的无服务器版本，以内容为中心，记录技术、生活与思考。首页把个人简介、实时天气、日历和文章浏览组合在一起，并使用液态玻璃效果呈现界面。

## 内容与功能

- 使用 Vue 3、TypeScript 与 Vite 构建单页应用。
- 文章、友链、相册和展览内容保存在仓库中的 Markdown 与 JSON 文件里，并可通过 Decap CMS 管理。
- 提供文章归档、日历、相册、友链和项目展览等页面。
- 液态玻璃效果不可用时会回退到 CSS 毛玻璃样式。

## 项目信息

- 原项目：[Nebula](https://github.com/haloo-cod/Nebula)
- 在线地址：[starlitn.top](https://starlitn.top/)
- 部署方式：静态站点，可托管到 Vercel，无需运行时后端。
